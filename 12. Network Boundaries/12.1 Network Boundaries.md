## 1. Router as Gateways:
The router provides a gateway through which hosts on one network can communicate with hosts on different networks. Each interface on a router is connected to a separate network.

Every host on a network must use the router as a gateway to other network. Therefore, each host must know the IPv4 address of the router interface connected to the network where host is attached. This address is known as the default gateway address. It can be either statically configured on the host or received dynamically by DHCP.
